## D2 成本情境與名單政策

依規格第 13 節已決策值，JSON 的 `scenario`：

| 欄位 | 主要值 |
|---|---|
| max_list_rate | 0.2 |
| loss_ratio | 0.5 |
| contact_cost | 50 |
| rescue_rate | 0.2 |

`cost_sensitivity` 四軸（包含主要值，C3 以四軸笛卡兒積列出81情境）：

| 欄位 | 值 |
|---|---|
| max_list_rate | [0.1, 0.2, 0.3] |
| loss_ratio | [0.5, 0.75, 1.0] |
| contact_cost | [50, 500, 2000] |
| rescue_rate | [0.1, 0.2, 0.3] |

損失_i＝max(9月帳單_i,0)×loss_ratio，帳單由 bill_at(df,0) 取得。
總成本＝FN損失加總＋TP損失×(1−rescue_rate)加總＋最終名單人數×contact_cost。
共用 choose_threshold 在 .05～.95、間隔 .01 的91點逐點先套用名單上限再算成本，同成本選較高門檻，不存在超額而無解的候選。
每批最終名單不超過 floor(max_list_rate×人數)，超額時完整精度分數降冪、同分ID升冪截取；原始名單與觸發上限均記錄。不同情境／上限記錄各自 policy_id。
同列上限下 Recall/F1、無上限成本及 F1 規則對照，不把情境結果稱為銀行實務最佳政策。
50% 只是參考監理參數下限的情境起始假設，非實際損失率；帳單非EAD，沒有真實損失及回收資料。依據及引用限制見規格 D2。
提前預警 F5 僅比較 AUC、固定比例涵蓋率，不套用此成本門檻。

舊式成本＝FN人數×平均損失＋TP人數×平均損失×(1−挽回比例)＋(TP＋FP)×聯絡成本。
舊二軸敏感度仍為原程式無上限對照；所有結果明標legacy，不能把它當成D2正式名單政策。

## G2b 替換條件與 D7

- 比較基準 M1-NS；候選也不含敏感屬性。含／不含敏感屬性的比較僅供 RQ1，不作替換依據。
- L1 OOF 同一切分、同一折；兩方皆用 Policy.top_n(0.2) 固定前20%，不是共同數值門檻。
- 三條件須同時成立：Recall提升至少 **0.01**；AUC **不低於** 基準；性別與年齡層各自EO差距增加均 **不超過0.02**。EO也在同一最終前20%名單計算。
- 這是事前工程選擇規則，不代表統計顯著；EO容許值不代表符合公平性。
- 多個候選同時達標時的最終採用順序／同分規則：規格未定，**待組長確認**，不自行以AUC最高決定。
- 各模型仍另列共同0.5無上限、固定前20%、自己的正式成本政策三種比較，不能混稱。
- G2b 依規格4.5.1建立模型＋政策清單，保留全部研究比較需要的模型；同模型不同政策共用model_hash、不同policy_id。正式門檻只由各自L1 OOF決定。

## D8 與族群門檻目標

- Recall分母（違約人數）或FPR分母（未違約人數）**少於93人**標為小樣本；93本身不標。每群列總人數、違約、未違約人數與Wilson score 95%區間。分母0時空值並標無法計算，不填0。
- 差距bootstrap：以客戶為單位、族群×標籤分層、2,000次、seed42，percentile 2.5/97.5%；有效重抽少於1,900次不產生可靠區間。模型差異用成對重抽。
- 族群門檻只作研究／模擬，不用於平台（D5）；性別、年齡層、性別×年齡層分別執行，每次互斥且完整。
- 07 現程式目標定義：同一模型、同一次訓練資料OOF，依單一門檻 t0 得到的整體Recall；各群找最接近該目標的Recall。不是指定固定Recall數值，也不是Hardt方法完整實作。
- JSON 的 `group_threshold.target_definition=single_policy_oof_recall`：同一模型、當次訓練資料OOF上，以主要成本政策的單一門檻 t0 得到的**原始名單（score>=t0，尚未截取上限）**整體Recall作目標。C2的_policy_for_split與07的目標計算均採原始單一門檻名單；不是套用上限後的Recall，不使用測試集決定目標。07指定run的t0須來自同模型自己的OOF政策。
- **待組長確認**：正式族群門檻的搜尋網格、差距同分處理是否沿用07現況（.05～.95、.01間隔；差距round到4位後同分取較高門檻）。這些是實作現況，不是規格明定數值。
- 族群政策最終名單上限20%；上限觸發後不保證各群Recall仍接近原目標，並列原始／最終名單結果。
